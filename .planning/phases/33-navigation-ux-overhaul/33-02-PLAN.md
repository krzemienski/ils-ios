Key architecture from research:
- `ActiveScreen` is a flat enum in SidebarRootView — switching to `.chat(session)` destroys the previous view
- `.chat(ChatSession)` must remain an `ActiveScreen` case to preserve `@SceneStorage("lastChatSessionId")` restoration
- Research recommends option (b): tracked `previousScreen` with custom back button (low complexity)
- Chat toolbar uses `.primaryAction` placement — does NOT conflict with hamburger
- In chat, the back button should REPLACE the hamburger as `.topBarLeading` (sidebar accessible via edge swipe)
- Must wrap `.topBarLeading` usage in `#if os(iOS)` / `#else` / `#endif` to avoid macOS build error
- `previousScreen` must be cleared when sidebar navigation changes `activeScreen` (Pitfall 5 from research)
- AppState currently has no `activeHostName` property — needs to be added
- SidebarView headerSection shows "ILS" + connection URL, with a green/red dot

Chat navigation entry points (all must set previousScreen):
1. SidebarView `onSessionSelected` callback (line ~198, ~311 in SidebarRootView)
2. HomeView `onSessionSelected` callback (line ~336 in SidebarRootView)
3. AppState `navigateToSession(id:)` via deep link (handled via navigationIntent onChange)
4. @SceneStorage restoration on launch (should NOT set previousScreen — no "back" from a restored session)
</context>

  <name>Task 1: Add previousScreen tracking and chat back button</name>
  <files>
    ILSApp/ILSApp/Views/Root/SidebarRootView.swift
    ILSApp/ILSApp/Views/Chat/ChatView.swift
  </files>
  <action>
    **In SidebarRootView.swift:**

    1. Add a new `@State` property after the existing `activeScreen` declaration:
       ```swift
       @State private var previousScreen: ActiveScreen? = nil
       ```

    2. Create a helper method for navigating to chat that records the previous screen:
       ```swift
       private func navigateToChat(_ session: ChatSession) {
           if case .chat = activeScreen {
               // Already in chat — just switch session, don't update previousScreen
               activeScreen = .chat(session)
           } else {
               previousScreen = activeScreen
               activeScreen = .chat(session)
           }
       }
       ```

    3. Replace ALL direct `activeScreen = .chat(session)` assignments with `navigateToChat(session)` calls. There are at least 4 call sites:
       - SidebarView `onSessionSelected` callback in iPhone layout (~line 198+311)
       - HomeView `onSessionSelected` callback (~line 336)
       - @SceneStorage restoration in `.task` — this one should NOT use `navigateToChat()` — keep it as direct `activeScreen = .chat(session)` since there is no meaningful "previous" on app launch

    4. In the `.onChange(of: appState.navigationIntent)` handler (~line 140), when the intent is `.chat`, call `navigateToChat(session)` instead of direct assignment. For non-chat intents, clear `previousScreen = nil` (sidebar-style navigation resets history).

    5. In all sidebar `onSessionSelected` closures and `sidebarNavItem` tap handlers that set `activeScreen` to a non-chat screen, add `previousScreen = nil` to clear stale back history.

    6. Pass an `onBack` closure to `ChatView` when `previousScreen != nil`:
       ```swift
       // In chatScreen computed property:
       ChatView(session: session, onBack: previousScreen != nil ? {
           if let prev = previousScreen {
               activeScreen = prev
               previousScreen = nil
           }
       } : nil)
       ```

    **In ChatView.swift:**

    1. Add an `onBack` parameter to the view:
       ```swift
       var onBack: (() -> Void)? = nil
       ```

    2. Add a back button to the toolbar when `onBack` is provided. The back button should REPLACE the hamburger (which is at the NavigationStack level and will be overridden). Use `#if os(iOS)` guard:
       ```swift
       // Add inside the .toolbar block:
       #if os(iOS)
       if let onBack {
           ToolbarItem(placement: .topBarLeading) {
               Button(action: onBack) {
                   HStack(spacing: 4) {
                       Image(systemName: "chevron.left")
                           .font(.system(size: 17, weight: .semibold))
                       Text("Back")
                           .font(.system(size: 17))
                   }
                   .foregroundStyle(theme.accent)
               }
               .accessibilityLabel("Go back")
           }
       }
       #endif
       ```

    Ensure existing ChatView callers that don't pass `onBack` continue to work (the default nil value handles this).
  </action>
