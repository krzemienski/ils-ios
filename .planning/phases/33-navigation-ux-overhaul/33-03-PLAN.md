<objective>
Fix deep link navigation so browser sub-routes select the correct segment and chat deep links integrate with the previousScreen back button.

Purpose: NAV-05 requires all registered `ils://` routes to navigate correctly without stale state. Research found two issues: (1) browser sub-routes (`ils://projects`, `ils://plugins`, `ils://mcp`, `ils://skills`) all navigate to `.browser` but do NOT set the initial segment — user always lands on the default segment regardless of which deep link was used; (2) chat deep links via `ils://sessions/{uuid}` don't integrate with the `previousScreen` tracking from Plan 02, so the back button won't work after a deep link.

Output: Deep links route correctly to browser segments and integrate with back button navigation.
</objective>

Key architecture:
- `AppState.handleURL()` sets `navigationIntent` which SidebarRootView consumes via `.onChange`
- `SidebarRootView` owns `@State private var browserSegment: BrowserSegment = .mcp`
- `BrowserView(initialSegment: browserSegment)` reads the segment on init
- Browser sub-routes need to communicate which segment to select — but AppState cannot directly set SidebarRootView's @State
- Solution: Add a `browserSegmentIntent: BrowserSegment?` property to AppState, consumed alongside `navigationIntent` in SidebarRootView's onChange handler
- The `navigateToChat()` helper from Plan 02 must be called for deep-linked chat sessions so `previousScreen` is set
- For non-chat deep links, `previousScreen` must be cleared (deep links are hard navigations)

Deep link routes from research audit:
- ils://home → .home (OK)
- ils://sessions/{uuid} → .chat(session) (needs previousScreen integration)
- ils://browser → .browser (OK — default segment fine)

- ils://plugins → .browser + Plugins segment (BROKEN — no segment set)
- ils://mcp → .browser + MCP segment (BROKEN — no segment set)

- ils://settings → .settings (OK)

- ils://fleet, ils://profiles → .hostProfiles (OK)

       ```swift
       .onChange(of: appState.navigationIntent) { _, intent in
           guard let screen = intent else { return }

           // Handle browser segment intent for deep links
           if case .browser = screen, let segmentIntent = appState.browserSegmentIntent {
               browserSegment = segmentIntent
               appState.browserSegmentIntent = nil
           }

           // Handle chat deep links through navigateToChat for back button support
           if case .chat(let session) = screen {
               navigateToChat(session)
           } else {
               activeScreen = screen
               previousScreen = nil  // Non-chat deep links clear back history
           }

           appState.navigationIntent = nil
           if !isRegularWidth {
               closeSidebar()
           }
       }
       ```
