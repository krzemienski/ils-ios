  <action>
Fix 3 macOS feature parity gaps identified in 38-RESEARCH.md. All changes are in `MacContentView.swift`.

**Gap 1: macOS sidebar does not show activeHostName**

In `MacContentView.sidebarContent`, add `activeHostName` display below the connection status indicator. Follow the iOS `SidebarView` pattern. The AppState `activeHostName` property (added Phase 33-34) is already accessible since both targets share AppState.

Pattern: in the sidebar header area, add a conditional display:
```swift
if let hostName = appState.activeHostName {
    Text(hostName)
        .font(.caption)
        .foregroundStyle(.secondary)
}
```

**Gap 2: macOS deep links don't consume browserSegmentIntent**

In `MacContentView.handleNavigationIntent()`, add consumption of `appState.browserSegmentIntent` when navigating to the browser screen. When `browserSegmentIntent` is set, navigate to `.browser` AND pass the segment intent so `BrowserView` picks it up.

Reference the iOS `SidebarRootView` pattern for how `browserSegmentIntent` is consumed:
- Set `activeScreen = .browser`
- `BrowserView` reads `browserSegmentIntent` from AppState environment

The macOS side just needs to ensure it sets `selectedScreen = .browser` when `browserSegmentIntent` is non-nil, and that `BrowserView` in the detail column receives the intent. Since BrowserView is shared, it already handles the intent.

**Gap 3: macOS sessionsViewModel not reloading on host switch**

Add `.onChange(of: appState.serverURL)` handler to `MacContentView` that reconfigures and reloads `sessionsViewModel`. Follow the pattern used by the 8 shared views in Phase 34.

Pattern:
```swift
.onChange(of: appState.serverURL) { _, _ in
    sessionsViewModel.reconfigure(appState: appState)
    Task { await sessionsViewModel.loadSessions() }
}
```

Check if `sessionsViewModel` has a `reconfigure(appState:)` method. If not, check how it initializes -- it may use `APIClient(baseURL: appState.serverURL)`. In that case, create a new sessionsViewModel instance or call its equivalent reload method.

After all 3 fixes: rebuild macOS to confirm zero errors.
```bash

  -destination 'platform=macOS' -quiet 2>&1 | tail -5
```
