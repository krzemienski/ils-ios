**Update MacSettingsView to use backend config with inheritance badges and tooltips on the General tab:**

1. **Replace the @AppStorage defaultModel with backend-driven model picker.**

The `@AppStorage("defaultModel")` property should be kept as a local fallback but the model Picker should read/write via the SettingsViewModel (same as iOS). Change the model Picker in `generalSettings` from binding to `$defaultModel` to binding to the effective config:

Replace the model Picker:
```swift
settingRow(label: "Default Model") {
    Picker("Default Model", selection: $defaultModel) {
        ForEach(availableModels, id: \.self) { model in
            Text(ClaudeModel.displayNameForID(model)).tag(model)
        }
    }
    .pickerStyle(.menu)
    .frame(width: 200)
}
```

With:
```swift
settingRow(label: "Default Model") {
    Picker("Default Model", selection: Binding(
        get: {
            viewModel.effectiveConfig?.config.model ?? viewModel.config?.content.model ?? defaultModel
        },
        set: { newModel in
            defaultModel = newModel  // Keep local fallback in sync
            viewModel.updateModel(newModel)
        }
    )) {
        ForEach(availableModels, id: \.self) { model in
            Text(ClaudeModel.displayNameForID(model)).tag(model)
        }
    }
    .pickerStyle(.menu)
    .frame(width: 200)
}
```

2. **Add inheritance badge + tooltip after the model Picker.** Insert right after the model Picker (before the Divider):

```swift

}
```
