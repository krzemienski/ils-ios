**UI-05: Rate limit countdown timer (SkillsViewModel)**

In `SkillsViewModel.swift`, add countdown state and timer logic:

1. Add two new properties near the existing `gitHubError` property:
   ```swift
   var rateLimitCountdown: Int = 0
   @ObservationIgnored private var countdownTask: Task<Void, Never>?
   ```

2. Add a `startCountdown()` method:
   ```swift
   private func startCountdown() {
       countdownTask?.cancel()
       rateLimitCountdown = 60
       countdownTask = Task { @MainActor [weak self] in
           while let self, self.rateLimitCountdown > 0 {
               try? await Task.sleep(for: .seconds(1))
               guard !Task.isCancelled else { return }
               self.rateLimitCountdown -= 1
           }
           guard let self, !Task.isCancelled else { return }
           self.gitHubError = nil
           self.rateLimitCountdown = 0
       }
   }
   ```

3. In the rate limit catch block (around line 204), after setting `gitHubError`, call `startCountdown()`:
   ```swift
   if desc.contains("rate limit") || desc.contains("429") || desc.contains("limit reached") {
       gitHubError = "GitHub rate limit reached"
       startCountdown()
   }
   ```
   Note: Set a clean user-facing message instead of the raw error.localizedDescription.
