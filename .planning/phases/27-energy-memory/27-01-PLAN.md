**HostProfilesViewModel.swift (ENRG-03):**
In `startHealthPolling(interval:)` (around line 71), the polling interval does not account for Low Power Mode. Modify the method to double the interval when LPM is active:

```swift
func startHealthPolling(interval: TimeInterval = 30) {
    healthTask?.cancel()
    // ENRG-03: Double fleet health poll interval in Low Power Mode to reduce energy.
    let effectiveInterval = LowPowerModeMonitor.shared.isLowPowerModeEnabled ? interval * 2 : interval
    healthTask = Task { [weak self] in
        while !Task.isCancelled {
            try? await Task.sleep(for: .seconds(effectiveInterval))
            guard let self, !Task.isCancelled else { break }
            await self.refreshAllHealth()
        }
    }
}
```

You will need to add `import Foundation` if not present (it likely is). The `LowPowerModeMonitor` is already used elsewhere in the codebase and should be importable without additional dependencies.

**CyberpunkEffects.swift (ENRG-05):**
In the `GlowEffect` ViewModifier (lines 6-17), the body applies TWO `.shadow()` calls which means two GPU blur render passes per frame. Reduce to a single shadow pass that achieves a similar visual effect:

```swift
struct GlowEffect: ViewModifier {
    let color: Color
    let radius: CGFloat
    let opacity: Double

    func body(content: Content) -> some View {
        content
            // ENRG-05: Single shadow pass instead of double — halves GPU blur render cost.
            .shadow(color: color.opacity(opacity), radius: radius * 1.5)
            .drawingGroup()
    }
}
```

The single shadow with `radius * 1.5` approximates the visual spread of the previous double-shadow without the second GPU pass. The `.drawingGroup()` is retained to flatten the compositing.
