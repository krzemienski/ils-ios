**Step 1: Add drawingGroup() to GlassCard**

In `GlassCard.swift`, add `.drawingGroup()` AFTER the `.shadow()` modifier (line 16) and BEFORE the closing brace of the `body` function. This offloads the shadow compositing to Metal:

```swift
.shadow(color: theme.accent.opacity(0.08), radius: 8, x: 0, y: 0)
.drawingGroup() // Offload shadow compositing to Metal
```

**IMPORTANT CAVEAT from research:** `drawingGroup()` rasterizes the entire subtree. GlassCard wraps interactive content (buttons, toggles). If this breaks interactivity during build testing, the fallback approach is:
- Remove `drawingGroup()` from the full modifier
- Instead, apply it only to a background ZStack layer that holds the background+shadow, keeping interactive content above it
- Test by building and running -- if buttons inside glass cards stop responding, use the fallback
