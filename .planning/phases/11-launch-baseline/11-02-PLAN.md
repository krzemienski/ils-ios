    Step 2: Capture the Instruments trace.
    - Run: `xcrun xctrace record --device 50523130-57AA-48B0-ABD0-4D59CE455F14 --template "App Launch" --launch com.ils.app --time-limit 10s --output .planning/phases/11-launch-baseline/evidence/launch-after.trace`

    Step 3: Extract metrics from the trace (if xctrace succeeded).
    - Run: `xcrun xctrace export --input .planning/phases/11-launch-baseline/evidence/launch-after.trace --toc` to list available tables
    - Extract timing data if possible with `xcrun xctrace export`

    - **CPU profile**: CPU usage during launch from xctrace OR note as "not measurable without physical device" with justification
    - **Simulator caveat**: Note that simulator timings are relative (not correlated with device performance) per 11-RESEARCH.md guidance
    - **Improvement**: Calculated percentage improvement (before vs after)
    - **Commit reference**: `84bbe08` (the code change commit)

    If xctrace completely fails to produce usable output, the structured text report alone satisfies the ROADMAP criterion when it documents actual observed millisecond timing from timestamped screenshot evidence.
