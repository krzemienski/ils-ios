    Read TeamsExecutorService.swift lines 89-116. If `Task.detached` still captures non-Sendable `Process` (line 104: `if process.isRunning`), fix it by extracting the Sendable `pid` value BEFORE the Task.detached boundary:
    ```swift
    func shutdownTeammate(teamName: String, memberName: String) {
        guard let process = activeProcesses[teamName]?[memberName] else { return }
        process.terminate()
        let pid = process.processIdentifier  // Int32 is Sendable
        // Only capture pid (Sendable), not process (non-Sendable)
        Task.detached {
            try? await Task.sleep(nanoseconds: 5_000_000_000)
            // Use kill() with pid directly — no Process reference needed
            kill(pid, SIGKILL)
        }
        activeProcesses[teamName]?.removeValue(forKey: memberName)
        if activeProcesses[teamName]?.isEmpty == true {
            activeProcesses.removeValue(forKey: teamName)
        }
    }
    ```
    The key change: remove `if process.isRunning` check from inside Task.detached. Just send SIGKILL to pid — if process already exited, kill() harmlessly returns -1/ESRCH. This avoids capturing the non-Sendable Process.
