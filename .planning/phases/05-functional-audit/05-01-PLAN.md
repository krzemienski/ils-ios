**FAUD-05: Deep links for all 12 routes**

Test each deep link route. For each: send URL, wait 2s, screenshot, verify correct screen.

The 12 routes (from ILSAppApp.swift handleURL):
1. `ils://home` -> Home/Dashboard
2. `ils://sessions` -> Home (sessions IS home)
3. `ils://sessions/{uuid}` -> ChatView for specific session (find a valid UUID first via curl)
4. `ils://browser` -> Browser (default tab)
5. `ils://projects` -> Browser (same as browser)
6. `ils://skills` -> Browser with Skills tab selected
7. `ils://mcp` -> Browser with MCP tab selected
8. `ils://plugins` -> Browser with Plugins tab selected
9. `ils://settings` -> Settings
10. `ils://system` -> System Monitor
11. `ils://fleet` or `ils://hosts` -> Hosts (Fleet Management)
12. `ils://themes` -> Themes

For each deep link:
1. `xcrun simctl openurl 50523130-57AA-48B0-ABD0-4D59CE455F14 "ils://{route}"`
2. If "Open in ILSApp?" dialog appears, use `idb_describe` to find the Open button and tap it. NOTE: the system dialog only appears on the FIRST deep link after app install. Subsequent links open directly.
3. Wait 2 seconds
4. Capture screenshot: `faud05-dl-{route}.png`
5. Read screenshot and verify correct screen displayed

To get a valid session UUID for route #3:
```bash
curl -s "http://localhost:9999/api/v1/sessions?limit=1" | python3 -c "import sys,json; d=json.load(sys.stdin); items=d.get('data',{}).get('items',[]); print(items[0]['id'].lower() if items else 'none')"
```

After all 12 tests, create a summary JSON:
```bash
cat > /tmp/ils-audit-evidence/phase5/faud05-deeplink-evidence.json << 'DEEPLINK_EOF'

    ... (one entry per route)
  ],

  "passed": N,
  "failed": N
}
DEEPLINK_EOF
```
