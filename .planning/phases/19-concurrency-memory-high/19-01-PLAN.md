Current code pattern (all three ViewModels):
```swift
@MainActor @Observable class FooViewModel {
    @ObservationIgnored nonisolated(unsafe) private var someTask: Task<Void, Never>?
    deinit { someTask?.cancel() }
}
```

Problem: `nonisolated(unsafe)` tells the compiler to skip isolation checks, but the property is on a @MainActor class. Since deinit is nonisolated, accessing a @MainActor property from deinit is the actual concern. The fix is to remove `nonisolated(unsafe)` and handle deinit correctly.
</context>

2. **Rewrite `startHealthPolling(interval:)`:**
```swift
func startHealthPolling(interval: TimeInterval = 30) {
    healthTask?.cancel()
    healthTask = Task { [weak self] in
        while !Task.isCancelled {
            try? await Task.sleep(for: .seconds(interval))
            guard let self, !Task.isCancelled else { break }
            await self.refreshAllHealth()
        }
    }
}
```
   The `[weak self]` prevents retain cycles. The `while !Task.isCancelled` + sleep-first pattern matches the Timer behavior (first fire after interval, not immediately).

3. **Rewrite `stopHealthPolling()`:**
```swift
func stopHealthPolling() {
    healthTask?.cancel()
    healthTask = nil
}
```

5. **Remove the `import Foundation` dependency on Timer** — it's still needed for Foundation types, so leave the import.
