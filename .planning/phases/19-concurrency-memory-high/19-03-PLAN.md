The heartbeat watchdog is at SSEClient.swift lines 130-140:
```swift
let heartbeatWatchdog = Task.detached { [weak self] in
    while !Task.isCancelled {
        try await Task.sleep(nanoseconds: 15_000_000_000)
        if await lastActivity.secondsSinceLastActivity() > 45 {
            AppLogger.shared.warning("SSE heartbeat timeout — no activity in 45s", category: "sse")
            throw URLError(.timedOut)
        }
        guard self != nil else { return }
    }
}
```

Issues:
1. Captures `[weak self]` but only uses it for a nil check (line 138). This is unnecessary — the watchdog's job is to throw a timeout error, which cancels the parent task's for-try-await loop. The parent Task already holds a `[weak self]` reference and handles cleanup.
2. `AppLogger.shared` is safe to call from any context (it uses OSAllocatedUnfairLock per 18-01 fix).
3. `lastActivity` is an actor, so `await lastActivity.secondsSinceLastActivity()` is correct.

Fix: Remove `[weak self]` capture entirely. The watchdog needs no reference to self — it only checks lastActivity and throws to signal timeout.
