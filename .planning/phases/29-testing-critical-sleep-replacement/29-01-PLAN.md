- These wait for data to load after navigating. Replace with waiting for either content cells to appear OR loading indicator to disappear OR empty state text to appear. Pattern:
  ```swift
  // Wait for loading to complete — content, empty state, or loading indicator gone
  let loadingDone = app.cells.firstMatch.waitForExistence(timeout: 5) ||
                    app.staticTexts["No Projects"].waitForExistence(timeout: 1)
  ```
  Adapt the empty-state text to match the view being tested (No Projects, No Skills, No MCP Servers, No Plugins).

For `sleep(2) // Give loading time to complete` (ErrorHandling line 297):
- Replace with `_ = waitForElementToDisappear(app.activityIndicators.firstMatch, timeout: 5)` or wait for cells/content.

For `sleep(1)` before taking screenshots or before interacting with UI (ErrorHandling lines 305, 387, 433):
- Replace with waiting for the specific element about to be interacted with: `_ = app.navigationBars.firstMatch.waitForExistence(timeout: 3)` or the specific button/field.

For `sleep(2)` after pull-to-refresh (ErrorHandling line 316, line 365):
- Replace with waiting for loading indicator to disappear or cells to refresh: `_ = waitForElementToDisappear(app.activityIndicators.firstMatch, timeout: 5)`

For `sleep(1)` and `sleep(2)` inside form validation flows (ErrorHandling lines 409, 467, 493):
- Replace with waiting for the expected condition (sheet still visible, error text appears, etc.). The code already checks for these conditions immediately after — just use `waitForExistence` on the expected element.

For `sleep(1)` after sheet dismiss (ErrorHandling line 433):
- Replace with `_ = waitForElementToDisappear(app.navigationBars["New Session"], timeout: 3)` or similar dismiss confirmation.

For `sleep(2)` after navigating in FeatureGateTests (lines 221, 326, 432, 701):
- Same as ErrorHandling: wait for content/cells/empty-state. Pattern: `_ = app.cells.firstMatch.waitForExistence(timeout: 5)`

- Replace with waiting for loading to complete: `_ = waitForElementToDisappear(app.activityIndicators.firstMatch, timeout: 5)` — this is inside a shared helper used by multiple tests.

- Wait for search field or content to be ready: `_ = app.searchFields.firstMatch.waitForExistence(timeout: 3)` or `_ = app.cells.firstMatch.waitForExistence(timeout: 3)`
