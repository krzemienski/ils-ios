**Screenshot strategy for macOS:**

The macOS app runs as a native window. Use `screencapture` to capture just the app window:

1. Find the window ID:
```bash
# List windows belonging to the macOS app
osascript -e 'tell application "System Events" to tell process "ILSMacApp" to get {name, position, size} of window 1'
```

2. Use `screencapture -l <windowID>` for the window only. To get the CGWindowID:
```bash
# Get window list and find ILSMacApp window
python3 -c "
import subprocess, json
result = subprocess.run(['osascript', '-e', 'tell application \"System Events\" to tell process \"ILSMacApp\" to get id of window 1'], capture_output=True, text=True)
print(result.stdout.strip())
"
```

If CGWindowID retrieval is complex, fallback approach:
```bash
# Bring app to front and capture the frontmost window
osascript -e 'tell application "ILSMacApp" to activate'
sleep 1
screencapture -w /tmp/ils-audit-evidence/phase1/macos/screenshot.png
```

Or simplest reliable approach -- capture the specific window by title:
```bash
osascript -e 'tell application "ILSMacApp" to activate'
sleep 1
# Use screencapture in window mode with CGWindowID
# Get CGWindowID from Quartz
python3 -c "
import Quartz
windows = Quartz.CGWindowListCopyWindowInfo(Quartz.kCGWindowListOptionOnScreenOnly, Quartz.kCGNullWindowID)
for w in windows:
    if 'ILS' in str(w.get('kCGWindowOwnerName', '')):
        print(f\"Window ID: {w['kCGWindowNumber']}, Owner: {w['kCGWindowOwnerName']}, Title: {w.get('kCGWindowName', 'N/A')}\")
"
```

Use the window ID with: `screencapture -l<windowID> /path/to/output.png`
