**TunnelSettingsView.swift (UIPERF-01):**

The `generateQRCode(from:)` static method uses `CIFilter.qrCodeGenerator()` and `CIContext.createCGImage()` which are CPU-intensive CoreImage operations. Currently called synchronously from:
- `onChange(of: tunnelURL)` (line 86)
- `fetchStatus()` (line 477)
- `startTunnel()` (line 500)
- `startCustomDomainTunnel()` (line 554)

Fix: Wrap each call site in a `Task.detached(priority: .userInitiated)` block so CIFilter runs off the main actor. Update the `@State private var qrImage` on `@MainActor` after generation completes.

Pattern for each call site — replace:
```swift
qrImage = Self.generateQRCode(from: url)
```
with:
```swift
let urlCopy = url
Task.detached(priority: .userInitiated) {
    let image = generateQRCode(from: urlCopy)
    await MainActor.run { qrImage = image }
}
```

Since `generateQRCode` is already `private static`, it is safe to call from a detached context. The `ciContext` is already a `static let` (thread-safe for CIContext).

Keep the `generateQRCode` method signature unchanged — only change the call sites.

**ToolCallAccordion.swift (UIPERF-04):**

The `toolIcon` and `toolColor` computed properties each call `toolName.lowercased()` and then chain 10+ `.contains()` checks. During streaming, the view body is re-evaluated on every tick, making this O(n*m) per frame where n = number of tool calls visible and m = number of contains checks.

Fix: Create a private enum `ToolCategory` with cases for each tool type (read, write, edit, bash, grep, glob, webSearch, webFetch, task, skill, list, other). Add a static method `classify(_ name: String) -> ToolCategory` that lowercases once and uses a single `if/else` chain. Store the result in a `let toolCategory: ToolCategory` property computed once in `init()`.

Then rewrite `toolIcon` and `toolColor` as simple `switch toolCategory` statements — no String operations at all.

The init already accepts `toolName`, so add:
```swift
private let toolCategory: ToolCategory
```

In init body, after `self.toolName = toolName`:
```swift
self.toolCategory = ToolCategory.classify(toolName)
```
