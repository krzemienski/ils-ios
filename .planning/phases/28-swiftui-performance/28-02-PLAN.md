**MacSessionsListView.swift (UIPERF-02):**

The `filteredProjectGroups` computed var (line 320-326) runs on every body evaluation — it filters `viewModel.projectGroups` by `searchText.lowercased()`. During typing this causes O(n) work per keystroke per frame.

Fix: Replace the inline computed var with a `@State private var filteredProjectGroups: [ProjectGroupInfo] = []` and update it via `.onChange(of:)` handlers on both `searchText` and `viewModel.projectGroups`.

1. Add `@State private var cachedFilteredGroups: [ProjectGroupInfo] = []`
2. Remove the `private var filteredProjectGroups` computed property
3. Replace all references to `filteredProjectGroups` with `cachedFilteredGroups`
4. Add a private method `updateFilteredGroups()` that implements the same logic:
   ```swift
   private func updateFilteredGroups() {
       guard !searchText.isEmpty else {
           cachedFilteredGroups = viewModel.projectGroups
           return
       }
       let query = searchText.lowercased()
       cachedFilteredGroups = viewModel.projectGroups.filter { group in
           group.name.lowercased().contains(query)
       }
   }
   ```
5. Call `updateFilteredGroups()` in `.onChange(of: searchText)` and `.onChange(of: viewModel.projectGroups)` on the body's VStack.
6. Also call it in the `.task` modifier after `loadProjectGroups()` completes.

**MacProjectsListView.swift (UIPERF-03):**

Same pattern — `filteredProjects` computed var (line 295-303) recalculates every body pass.

Fix: Same approach as above:
1. Add `@State private var cachedFilteredProjects: [Project] = []`
2. Remove the `private var filteredProjects` computed property
3. Replace all references to `filteredProjects` with `cachedFilteredProjects`
4. Add a private method `updateFilteredProjects()`:
   ```swift
   private func updateFilteredProjects() {
       guard !searchText.isEmpty else {
           cachedFilteredProjects = viewModel.projects
           return
       }
       let query = searchText.lowercased()
       cachedFilteredProjects = viewModel.projects.filter { project in
           project.name.lowercased().contains(query) ||
           (project.description?.lowercased().contains(query) ?? false) ||
           project.path.lowercased().contains(query)
       }
   }
   ```
5. Call `updateFilteredProjects()` in `.onChange(of: searchText)` and `.onChange(of: viewModel.projects)`.
6. Also call it in the `.task` modifier after `loadProjects()` completes.
