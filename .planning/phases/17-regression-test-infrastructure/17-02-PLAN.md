  <action>
Create `ILSApp/ILSApp/Services/PerformanceMonitor.swift`:

```swift
import MetricKit
```

- `final class PerformanceMonitor: NSObject, MXMetricManagerSubscriber`
- `static let shared = PerformanceMonitor()`
- `private override init() { super.init() }` -- singleton, not publicly constructable.
- `func start()`: Call `MXMetricManager.shared.add(self)` and log registration via `AppLogger.shared.info("MetricKit subscriber registered", category: "performance")`.
- `func stop()`: Call `MXMetricManager.shared.remove(self)`.

Implement the two required delegate methods:

**`func didReceive(_ payloads: [MXMetricPayload])`:**
- Iterate payloads. For each:
  - If `payload.applicationLaunchMetrics` is non-nil, log `"MetricKit launch: timeToFirstDraw=\(launch.histogrammedTimeToFirstDraw)"` via `AppLogger.shared.info(_, category: "performance")`.
  - If `payload.memoryMetrics` is non-nil, log `"MetricKit memory: peak=\(memory.peakMemoryUsage)"`.
  - Log the full payload JSON via `payload.jsonRepresentation()` for archival. Use `AppLogger.shared.info("MetricKit payload: \(payload.jsonRepresentation())", category: "performance")`.

**`func didReceive(_ payloads: [MXDiagnosticPayload])`:**
- Iterate payloads. For each:
  - Log via `AppLogger.shared.error("MetricKit diagnostic: \(payload.jsonRepresentation())", category: "performance")`. Use error level because diagnostics represent crashes, hangs, or CPU exceptions.

Guard with `#if canImport(UIKit)` / `#endif` around the entire file since MetricKit is not available on macOS. This prevents macOS compilation issues since both targets share some source paths.

Do NOT import UIKit directly -- MetricKit is sufficient. The `#if canImport(UIKit)` guard handles platform availability.

Inside the existing `.task` modifier block (after the `Task.detached(priority: .background)` that initializes TipKit and CacheService), add:

```swift
#if canImport(UIKit)

#endif
```

Place it AFTER the `Task.detached` block but still inside `.task {}`. This ensures:
1. The first frame is already rendered (`.task` fires after first frame).
2. Registration is not on a background thread -- `MXMetricManager.shared.add()` is thread-safe but the subscriber callbacks will come on an arbitrary queue, which is fine since PerformanceMonitor uses AppLogger (which is Sendable).
3. The `#if canImport(UIKit)` guard prevents compilation on macOS.

Do NOT move it into the `Task.detached` block -- MetricKit registration should happen promptly after first frame, not deferred to a background priority task.

Also verify the macOS scheme still builds after this change (the guard should prevent any issues).
