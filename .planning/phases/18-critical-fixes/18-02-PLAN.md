Add exponential backoff with hash-based change detection to TeamsViewModel polling:

1. Add static constants: `minPollInterval: TimeInterval = 15`, `maxPollInterval: TimeInterval = 120`, `backoffMultiplier: Double = 1.5`
2. Add instance properties: `currentPollInterval: TimeInterval` (starts at min), `previousTeamHash: Int` (starts at 0)
3. Create `computeTeamHash() -> Int` that hashes team name + members count + tasks count + messages count from `selectedTeam`
4. In the polling loop (`startPolling`), after each `loadTeamDetail(name:)`:
   - Compute new hash
   - If hash matches previous: `currentPollInterval = min(currentPollInterval * Self.backoffMultiplier, Self.maxPollInterval)`
   - If hash differs: `currentPollInterval = Self.minPollInterval` and update `previousTeamHash`
5. Use `currentPollInterval` for `Task.sleep(nanoseconds:)` instead of hardcoded 15s
6. Ensure `guard !Task.isCancelled else { break }` after every sleep to prevent extra polls after stopPolling()

Note: `AgentTeam.members` is `[TeamMember]` (non-optional) -- use `selectedTeam?.members.count` not `selectedTeam?.members?.count`.
