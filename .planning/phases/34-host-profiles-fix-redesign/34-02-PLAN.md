<objective>
Add reactive ViewModel reconfiguration to all views that use `configure(client:)`, ensuring they reload data from the new host when AppState.serverURL changes.

Purpose: Without this, views that are already mounted when the user switches hosts will continue showing stale data from the previous host. The `.task` modifier only fires once per view identity — `.onChange(of: appState.serverURL)` is needed to re-inject the new APIClient and trigger a data reload.

Output: 8 views gain `.onChange(of: appState.serverURL)` handlers that reconfigure their ViewModels and reload data.
</objective>
