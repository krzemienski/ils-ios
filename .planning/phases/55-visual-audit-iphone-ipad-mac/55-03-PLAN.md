- macOS build scheme: ILSMacApp
- Build destination: platform=macOS
- DerivedData app path: ~/Library/Developer/Xcode/DerivedData/ILSApp-*/Build/Products/Debug/ILSMacApp.app

- Keyboard shortcuts: Cmd+1..4 (Navigate menu), Cmd+, (Settings), Cmd+N (New Session)
- Custom menus: Navigate, Session (Cmd+Shift+R/F/E)

macOS screenshot capture:
- Get window ID: `python3 -c "import Quartz; wins = Quartz.CGWindowListCopyWindowInfo(Quartz.kCGWindowListOptionOnScreenOnly, Quartz.kCGNullWindowID); [print(w['kCGWindowNumber']) for w in wins if w.get('kCGWindowOwnerName','') == 'ILSMacApp' and w.get('kCGWindowLayer',0) == 0]"`
- Capture: `screencapture -l $WID -x <path>`
- IMPORTANT: Window IDs change on app restart — re-query before each capture or use tight loop
