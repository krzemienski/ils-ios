
Wait 5 seconds for simulators to fully boot. Verify both are booted:
```bash

```
Both should show `(Booted)`.

**Step 2: Override status bars to 9:41 (for clean evidence screenshots)**
```bash
for UDID in "$IPHONE_UDID" "$IPAD_UDID"; do
  xcrun simctl status_bar "$UDID" override \
    --time "9:41" \
    --batteryState charged \
    --batteryLevel 100 \
    --cellularBars 4 \
    --wifiBars 3
done
```

**Step 3: Uninstall old app (clears stale UserDefaults), install fresh binary**
```bash
APP_PATH=$(ls -td ~/Library/Developer/Xcode/DerivedData/ILSApp-*/Build/Products/Debug-iphonesimulator/ILSApp.app 2>/dev/null | head -1)

for UDID in "$IPHONE_UDID" "$IPAD_UDID"; do
  xcrun simctl uninstall "$UDID" com.ils.app 2>/dev/null || true
  xcrun simctl install "$UDID" "$APP_PATH"
done
```

**Step 4: Launch app on both simulators and wait for auto-connect**
```bash
xcrun simctl launch "$IPHONE_UDID" com.ils.app
xcrun simctl launch "$IPAD_UDID" com.ils.app
```
Wait 5 seconds for the app to launch, discover the backend at localhost:9999, and auto-connect.

IMPORTANT (Pitfall 6): The app must be launched at least once BEFORE using deep links. Otherwise iOS shows a confirmation dialog instead of navigating.
