<objective>
Two independent agents verify that the Phase 40 setup is correct before validation begins. Each agent checks all setup conditions without seeing the other's work. 2/2 agreement is required.

Purpose: Prevents false confidence from confirmation bias. A single agent might overlook a subtle issue (wrong binary, stale data, iPad in compact mode). Two independent checks catch what one misses.
Output: Two verdict files in /tmp/v3.5-evidence/gate/ confirming (or denying) setup readiness.
</objective>
