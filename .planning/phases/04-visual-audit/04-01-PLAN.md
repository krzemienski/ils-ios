    Grep for ALL hardcoded font sizes: `size:`, `.font(.system(size:`, `Font.system(size:`.
    From prior work, zero `size: 10` should remain (39 instances were eliminated in HIG font compliance pass).
    Verify: zero instances of `size: 10` or below (except `size: 11` in LaunchScreenView which is allowed).

    If violations found, fix them by replacing with `theme.fontCaption` (11pt) or `theme.fontBody` (15pt).
    Save to `/tmp/ils-audit-evidence/phase4/code-audit-font-sizes.txt`.

    **Theme Token Audit (VAUD-04 continued):**
    Also grep for hardcoded Color literals that should use theme tokens: `.foregroundColor(.gray)`, `Color.white`, `Color.black`, `Color(.systemBackground)`.
    Document violations but do NOT fix color literals in this task (theme color handling is addressed in Plan 04-02 dark mode audit). Only fix font size violations here.
