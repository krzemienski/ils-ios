### Integration Gap (1 low-severity)

**macOS custom theme cold-load missing** (SYS-03 partial)
- `MacContentView.swift` `.task` (lines 100-107) loads `sessionsViewModel.loadProjectGroups()` but does NOT call `themeManager.loadAndRegisterCustomThemes(client:)`
- iOS `SidebarRootView.swift` (lines 186-188) calls both
- **Impact:** Custom themes from backend not shown in macOS theme picker on cold start. Appear after any host switch. Built-in themes (13) unaffected.
- **Fix:** Add `await themeManager.loadAndRegisterCustomThemes(client: appState.apiClient)` to MacContentView `.task`
