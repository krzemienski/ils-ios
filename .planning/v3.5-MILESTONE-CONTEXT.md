Launch every screen on iPhone AND iPad simulators, capture screenshot evidence, verify logs, fix issues on the spot, and have two independent agent teammates confirm all evidence.

## PASS Criteria Per Screen
Each screen must show:
1. Screenshot with real data (not empty state, not loading spinner, not error)
2. Correct navigation (sidebar accessible, back button where expected)
3. No crash in logs during/after navigation
4. Correct data from backend (session counts match, server counts match, etc.)

## Phases (4 phases, starting at Phase 40)

### Phase 40: Environment Setup & Screen Inventory
- Create iPad Pro simulator
- Boot both iPhone and iPad simulators
- Verify backend running on port 9999
- Build and install app on both devices
- Inventory all screens with exact PASS criteria and skill requirements

### Phase 41: iPhone Full Validation
- Navigate to every screen via deep links and sidebar
- Screenshot each screen (numbered: 01-home, 02-sessions, etc.)
- Capture and grep logs for errors/crashes
- Fix any issue found immediately, rebuild, re-validate
- Evidence dir: `/tmp/v3.5-validation/iphone/`

### Phase 42: iPad Full Validation
- Same screens on iPad
- Verify split-view / NavigationSplitView layout
- Screenshot each screen (numbered)
- Fix any issues (especially layout/sizing)
- Evidence dir: `/tmp/v3.5-validation/ipad/`

### Phase 43: Evidence Gate
- Two independent agent teammates read EVERY screenshot
- Both must confirm PASS/FAIL for each screen
- Cross-device comparison (iPhone vs iPad)
- Final verdict requires 2/2 agreement
- Any disagreement triggers re-validation
